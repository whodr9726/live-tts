# 语音规则（粘进项目的 AGENTS.md）

## 每轮默认：先朗读，再输出文字

1. 想好这轮要说的内容：口语化、短句、1~3 句。
2. 把**只包含要朗读的正文**写入 `.cache/tts/reply.txt`（UTF-8）。
   中文解释、代码块、表格、路径、日志**不要**写进去。
3. 后台朗读（约 0.1 秒返回，边合成边播放）：

   ```bash
   python .agents/skills/live-tts/say.py --file .cache/tts/reply.txt --detach
   ```

4. 立刻在界面输出文字回复。

## 例外

- 纯技术任务（改代码、查文件、装环境、看日志）默认**不朗读**；用户说"读出来"再读。
- 用户说"安静一下 / 别读了" → `python .agents/skills/live-tts/say.py --stop`，
  并且本轮之后不再朗读，直到用户说继续。
- 用户说"太快 / 慢一点" → 命令加 `--rate 0.85`；"太慢" → `--rate 1.1`。

## 不要

- 不要朗读代码块、命令输出、文件路径、JSON、链接、表格。
- 不要用浏览器 `speechSynthesis` 或系统 SAPI 兜底。
- 不要在朗读文件里混入 Markdown 标记或中文技术说明（除非用户要求中文朗读）。
